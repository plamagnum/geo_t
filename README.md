# Топографічні карти — навчальний вебзастосунок

Статичний інтерактивний матеріал українською мовою для уроків географії у 8 класі. Застосунок працює без збірки та npm-залежностей: лише HTML, CSS і JavaScript з Canvas API. Сторінку обслуговує nginx у Docker-контейнері.

## Запуск

```sh
docker compose up -d --build
```

Відкрийте [http://localhost:8080](http://localhost:8080). Щоб зупинити контейнер, виконайте `docker compose down`.

## Структура

| Файл | Призначення |
| --- | --- |
| `Dockerfile` | Образ nginx, статичні файли та перевірка працездатності |
| `docker-compose.yml` | Сервіс `topo-maps` на порту 8080 |
| `nginx.conf` | UTF-8, стиснення та резервний маршрут |
| `src/index.html` | Розмітка уроку й елементи керування |
| `src/styles.css` | Адаптивне оформлення |
| `src/app.js` | Масштаб, азимут, горизонталі, умовні знаки та тест |
| `src/extra.js` | Математична основа, форми рельєфу й координати |

## Вкладки

| Вкладка | Зміст |
| --- | --- |
| Масштаб | Іменований масштаб і перерахунок відстаней |
| Мат. основа | Проєкція, номенклатура та Балтійська система висот |
| Азимут | Компас і тренажер визначення напрямків |
| Горизонталі | Гіпсометрична карта та профіль рельєфу |
| Форми рельєфу | Моделі форм, бергштрихи та крутизна схилу |
| Координати | Кілометрова сітка, координати й орієнтування |
| Умовні знаки | Вікторина та довідник |
| Тест | Підсумкові шість запитань |

**Методична порада.** Покажіть учням гору і западину з однаковими замкненими горизонталями. Запропонуйте визначити форму за бергштрихами: вони спрямовані вниз по схилу, тому на горі дивляться назовні, а в западині — всередину.
